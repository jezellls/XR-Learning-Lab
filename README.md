# XR Learning Lab: VR First Aid Training & Performance Analytics

## Project Overview

XR Learning Lab is an independent research and development project exploring how virtual reality can support hands-on learning and how data analytics can be used to evaluate training performance.

The goal is to develop an interactive VR first-aid training simulation using Unity and the Meta Quest headset. The application will eventually collect performance data to analyze how users complete tasks, where they make mistakes, and how their performance changes over multiple attempts.

**Project Status:** In Progress — Started November 2026

## Research Question

Can performance data collected during immersive VR training help identify when learners struggle and may benefit from additional guidance?

## Planned Technologies

- Unity and C# — VR simulation development
- Meta Quest — VR hardware
- XR Interaction Toolkit — Virtual object interactions
- Python and pandas — Data processing and analysis
- Streamlit — Interactive analytics dashboard
- scikit-learn — Exploratory machine learning

## Planned Features

- Interactive VR first-aid training environment
- Guided training instructions and object interactions
- Performance tracking for completion time, errors, and attempts
- Python dashboard for visualizing training performance
- Exploratory machine learning for analyzing learner outcomes

## Development Roadmap

- [ ] Set up Unity and Meta Quest development environment
- [ ] Create a basic first-aid training scene
- [ ] Implement object grabbing and task interactions

- [ ] Record user performance data
- [ ] Build a Python analytics dashboard

## Research Notes

This project is in its early development stage. Planned features are not yet implemented. The first-aid scenario is intended as an educational prototype and will be developed using appropriate first-aid references.
